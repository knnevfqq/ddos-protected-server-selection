## 30G、100G、300G 怎么选：按攻击峰值，不按套餐大小

防御值是高防这行的定价主轴。同一家服务商、几乎相同的硬件，防御从 30G 加到 150G，月付从 ¥1188 涨到 ¥6888，这是华纳云 2022 年 8 月公开的独立服务器报价。所以正确的顺序是先估算自己被打时的峰值，再挑档，而不是「越大越安心」。

- **从没被打过，只是听到 CC 这个词有点慌**：LAX-STARTER，$200/年。防护当保险，钱留给 CDN 和备份更实在。
- **被打过，峰值在个位数 G，主要是 UDP flood、SYN flood 这类流量型**：重点看端口和流量包，而不是防御数字。10Gbps 端口本身能吸收一波流量，LAX-MEDIUM 的 20TB 月流量比 STARTER 的 5TB 更影响你能不能撑过那几天。
- **被打时带宽没跑满，但 CPU 100%、数据库连接数爆、页面转圈**：这是 CC，不是流量型 DDoS，把防御从 30G 加到 300G 不会让情况变好，要解决的是应用层。
- **业务不能中断，攻击常态化**：支付、游戏登录、直播推流这类，别在 VPS 上赌，直接比价带清洗承诺的高防独服，预算按每月几千元准备。

## CC 和 DDoS 不是一回事，官网只写了 DDoS

CC 攻击打应用层。攻击者用大量看起来正常的 HTTP 请求占满 PHP-FPM、数据库连接或搜索接口，带宽可能只跑了几十 Mbps，站点已经打不开了。流量清洗设备看的是包速率、连接数、异常 payload，对「每个 IP 每秒几个请求、UA 正常、带 Cookie」的请求不一定拦得住。

SixtyNet 官网 LAX 系列每档都标了 DDOS Protection，但没有公开 CC 防护的指标、触发阈值或 WAF 规则说明。行业里常见的「无视 CC」「金盾抗 CC」「清洗效率 99%」都是服务商自己的宣传口径，公开资料里找不到第三方验证过的拦截率数据，SixtyNet 也一样没有。所以这一项不能看宣传语，要问：

1. CC 触发条件能不能自己设？按 QPS、并发连接数，还是单 IP 请求频率？
2. 被 CC 期间能不能提供拦截报表，包含总请求数、拦截数、误杀情况？
3. 除了流量清洗，有没有 JS 挑战、人机校验、可自定义的 WAF 规则？
4. 攻击流量计不计入月流量包，超了怎么算？

这四个问题里，第 1 和第 4 个决定你能不能用，第 2 个决定出事时对方能不能配合你排查。答不上来的，别指望出事时有人帮你扛。

## 线路与延迟：150–200ms 是这类机器的正常水平

SixtyNet 的 LAX 系列走的是自家标称的精品网（按套餐分 2G、4G、10G），另外单独有一条 China Unicom-Premium 产品线，走联通 AS9929，100M 基础带宽、3 倍突发、95 计费，$2500/年，适合对回国线路质量要求高、但不需要 DDoS 防护的业务。

延迟方面，2026 年初有第三方测评对 SixtyNet 做过国内多节点测试，多数地区落在 150–200ms，属于美国西海岸机房的正常区间。另有一份 2023 年对别家 AS9929 线路的实测，回程走 AS9929，国内 ping 在 143–170ms，那不是 SixtyNet 的数据，只说明这条线路大概能到什么水平。

判断标准很简单：静态站、外贸展示站、面向海外的独立站，150–200ms 完全能用；游戏对战、实时音视频、强交互 API，这个延迟不适合，换到亚太机房更实际。

## 常见问题

**美国服务器需要备案吗？**
不需要。备案管的是中国大陆境内机房，美国机房不涉及这个流程，域名解析过去就能开。

**被攻击时会不会额外收带宽费？**
高防行业里的通行说法是清洗过的攻击流量不计入额外带宽费用，这是华纳云 2023 年的表述。但 SixtyNet 是按流量包卖的，攻击流量是否计入那 5TB，得让客服用文字确认，别只听口头答复。

**能不能只买高防 IP，转发到别的地方？**
在官网当前的 VPS 产品页里没有看到单独售卖的高防 IP 产品，只有整机套餐。需要独立高防 IP 的话要单独问。

**以后防御不够用了能升级吗？**
套餐页没有写升级规则，是否换机、是否补差价、数据怎么迁，都要问客服确认。

**能退款吗？**
官网只在个别住宅 IP 产品的说明里写了退款仅退到账户余额，LAX 系列的退款条款没有明确列出。按月付试一个月，比年付后扯皮划算。
